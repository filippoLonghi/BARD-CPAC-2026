# Hackathon 2025 Legacy Code

This folder contains standalone prototype scripts from the earlier BARD hackathon phase.
They are kept for reference only and are not imported by the active `bard_core` package.

- `prototype_scripts/BARD_legacy.py`: original one-file prototype pipeline.
- `scripts/send_demo_story.py`: hardcoded OSC demo sender.
- `scripts/voice_server_edge.py`: optional local narrator voice server experiment.
